# 星轨 bookmark-nav-site · 开发规范

> 沉淀自 2026-09 后台样式整改（间距失效排查等大量踩坑）。面向后续新功能开发，Agent 与人读均适用。
> 技术栈：Next.js 16 + React 19 + Tailwind 4 + Supabase + Vercel 自动部署（GitHub Actions）。

## 一、构建与验证（铁律）

1. **构建必须看真实退出码**，禁止管道掩盖：
   ```bash
   npm run build > /tmp/b.log 2>&1; echo "EXIT $?"
   ```
   禁止 `npm run build 2>&1 | tail -3`（管道让退出码恒为 0，曾因此把坏构建推上去了）。
2. **构建失败先看 `grep -n error /tmp/b.log`**，常见两类：
   - `Unterminated regexp literal` → JSX 结构残留（见 §二.4）
   - `Cannot find module .../login/page.js` → 删页后 `.next` 类型缓存残留，`rm -rf .next` 再 build。
3. **提交前复核**：`git status --short` + `git log --oneline origin/main -3`，确认链无分叉、无漏提交。
4. **改完 = commit + push → 等 75–80s → curl 验证**，不是本地 OK 就完事。

## 二、代码编辑规则

1. **JSX/TSX 精确替换用 Python 脚本**（`io.open` + `assert s.count(old)==1` + `replace`），不用 Edit 工具（本项目多次报 "File has not been read"）。
2. **禁止"截取重组"移动 JSX 区块**：曾用 `s[head:] + block + s[tail:]` 交换两个区块，误删了文件头（import / return / 弹窗区块全丢）。正确做法是**相邻块整体字符串替换**（`old_combined → new_combined`），替换后校验：
   - `import` 还在（文件前 200 字符）
   - `<div>` / `</div>` 数量平衡
   - 文件尾完整（`  );\n}` 收尾）
3. **替换后构建验证**，构建失败立即检查文件尾部是否有孤立 `))}`、重复 `</div>`（列表替换曾残留导致 Unterminated regexp）。
4. **删除页面/路由**：`rm -rf` 目录 + 全局 grep 残留引用（`grep -rn '"/login"' src`），并清理 `.next` 类型缓存。

## 二点五、Supabase 数据获取规则

1. **session 状态双通道去重**：`getSession()` 与 `onAuthStateChange`（注册时会推 INITIAL_SESSION）都会返回当前 session，且**对象引用不同**。直接 setUser 会让依赖 `[user]` 的 effect 重复执行 → 重复查询。
   - 正确姿势：`setUser` 前用 `useRef` 记录 uid，同 uid 跳过（NavBar 已实现，可复用）。
2. **同一数据多组件共享**：多个组件各自查同一张表（如 profiles）会重复请求；后续可加模块级 promise 缓存（同 uid 并发只发一次）。
3. **区分 SSR 与客户端查询**：首页 bookmarks 走服务端直查（浏览器 Network 看不到），客户端查询（nav-bar profile 等）才出现在 DevTools。

## 二点六、通用交互模式（抽屉菜单）

1. **交互**：点 Logo（nav-logo button）展开/收起抽屉，`aria-expanded` 标注；遮罩点击、ESC、菜单项跳转后均关闭。
2. **状态**：抽屉与遮罩**始终挂载**，用 `transform: translateX(-100%) ↔ 0` + transition 切换，隐藏态 `visibility: hidden` + `inert` 防止 Tab 聚焦（React 19 支持 boolean inert）。
3. **锁滚动**：展开时 `body.style.overflow = "hidden"`，关闭恢复（useEffect 清理）。
4. **菜单内容**：只放顶级页面（首页/关于），**分类属于首页内部结构，不进菜单**。
5. 视觉：`--bg-glass` 玻璃拟态 + 240px 宽 + 100dvh 高，active 项 `color-mix(in srgb, var(--accent) 14%, transparent)` 底 + accent 字。

## 二点七、外部实时数据（行情页）

1. **国内数据源**：东方财富 push2 接口（免费、无需 key、**支持浏览器直连 CORS**，已验证）。
2. **上期所金属主连 secid**（市场 113）：`113.aum` 沪金 / `113.agm` 沪银 / `113.cum` 沪铜 / `113.alm` 沪铝 / `113.znm` 沪锌 / `113.nim` 沪镍 / `113.snm` 沪锡 / `113.pbm` 沪铅。主连代码 = 品种码 + `m`（次主连 `s`）；市场 114=大商所、115=郑商所。
3. **批量行情**：`https://push2.eastmoney.com/api/qt/ulist.np/get?fltt=2&invt=2&fields=f2,f3,f4,f12,f14&secids=113.aum,...&ut=fa5fd1943c7b386f172d6893dbfba10b`；`f2` 最新价、`f3` 涨跌幅%、`f4` 涨跌额、`f12` 代码、`f14` 名称（fltt=2 已处理小数）。
4. **国际数据源 = Yahoo Finance（自家代理 `src/app/api/market/intl/route.ts`）**：`https://query1.finance.yahoo.com/v8/finance/chart/{GC=F|SI=F|HG=F}?interval=1d&range=1d`，读 `meta.regularMarketPrice` / `chartPreviousClose`；黄金兜底东财 `123.HLAU`（港伦敦金）。**死路勿再试**：新浪 `hq.sinajs.cn`、腾讯等国内行情接口——Vercel 海外节点访问会超时/被拒；Yahoo 本机直连也不通（国内网络），但 Vercel 海外正常。
5. **单位与换算**：纽约金/银 美元/盎司；美铜 `hf_HG` 美元/磅 → 美元/吨 `price × 2204.62`。国内：沪金 元/克、沪银 元/千克、其余金属 元/吨；非交易时段接口返回最近收盘价。
6. **前端双源容错（必须遵守）**：国内（浏览器直连东财）与国际（自家代理）**各自 `.catch` 独立 setState，互不拖累**；禁止 `Promise.all` 绑定两源——任一源失败只影响自己那一栏（国内失败红条提示，国际失败卡片显示 `--`），页面不得整体报错。
7. **代理超时控制**：Vercel 免费版函数时长上限 10s（Pro 默认 15s，可配更高），外部 fetch 必须带 AbortController 超时（本项目统一 6s），否则慢源会撞 504（FUNCTION_INVOCATION_TIMEOUT）。
8. **前端轮询**：5 分钟（300000ms）setInterval + 卸载清理；失败展示错误提示 + 手动刷新按钮；涨红跌绿（A 股习惯）。
9. **保活脚本**：`scripts/keep-alive.sh` 每 N 秒 ping 站点保持实例热（Vercel 空闲约 5 分钟后冷启动）；默认 9s 可调；`nohup ./keep-alive.sh > keepalive.log 2>&1 &` 后台常驻。

## 三、样式规则（本次最大教训）

### 3.1 @layer 优先级 —— 全局第一坑
- **CSS 层叠：非 `@layer` 的规则优先级 > `@layer` 内所有规则**。
- Tailwind 4 的 utility（`p-*`、`m-*`、`gap-*` 等）全部在 `@layer utilities`。
- **禁止在 globals.css 写非 layer 的全局 reset**，例如 `* { margin:0; padding:0 }`——它会把所有 Tailwind padding/margin 类压成 0（而 `flex`/`gap` 不受影响，页面"看起来正常"极具迷惑性）。
- reset 交给 Tailwind preflight（在 `@layer base`，自动生成），不要手写。
- 自定义样式若必须覆盖 utility，放进 `@layer components` 或 `@layer utilities`，或提高特异性。

### 3.2 间距规范（后台 /admin 已落地，新功能沿用）
| 位置 | 值 |
|---|---|
| 标题栏 → 统计卡 | 40px |
| 统计卡 → 表格 | 56px |
| 统计卡内边距 | 32px（p-8） |
| 表格行上下内边距 | 20px |
| 表格列间距 / 行内图标↔名字 | 20px |
| 操作按钮间距 | 16px |
| 表格行水平内边距 | 24px（px-6） |
| 首页区块间距 | 32–40px |
| 卡片间 gap | 16px |

### 3.3 inline style 双保险策略
- 关键间距（区块间 margin、卡片 padding、行内 gap）**优先写 inline style**：
  ```tsx
  <div style={{ marginBottom: 56, padding: 32, gap: 20 }}>
  ```
  不依赖 Tailwind CSS 文件加载，任何缓存/CDN 异常下必定生效（曾因 CDN 给浏览器旧 CSS 导致 Tailwind 类全部失效，inline 是最终兜底）。
- Tailwind 类保留一份（语义可读），inline 值必须与类一致，改一处同步两处。

### 3.4 容器规范
- 全局盒子统一用 `.container`（globals.css：`max-width:1280px; margin:0 auto; padding:40px 32px 80px`）。
- 首页与后台必须用同一个 `.container`，禁止后台另用 `max-w-6xl`（1280 vs 1152 视觉错位）。

### 3.5 视觉体系（沿用，勿改）
- 分类色映射（getCategoryColor）：frontend `#10b981` / work `#8b5cf6` / ai-tools `#ec4899` / tech-news `#f59e0b` / 默认 `#3b82f6`。
- 胶囊：`background: color+"1f"; border: 1px solid color+"55"; color: color`。
- 图标块：`color+"1f"` 底 + 彩色字，圆角 10px。
- 辉光：`--accent-glow` 背景 + `--accent-light` 图标色 + 数字 `text-shadow`。

## 四、后台布局规范
- 顺序固定：**标题栏（含主操作按钮）→ 统计卡 → 数据表格**。
- 统计卡：3 张（总用户 / 今日活跃 / 当前在线），`grid-cols-1 sm:grid-cols-3`，图标 + 数字 + 标签，hover 上浮。
- 表格（方案 A 现代表格）：表头四列（网站/分类/大小/操作）+ `grid-cols-[1fr_118px_84px_110px]`；行 hover 背景提亮 + 左侧 3px 分类色竖条（`.admin-row` 类）。
- 编辑/删除用图标按钮（w-8 h-8 圆角），编辑 hover 青、删除 hover 红。
- 新增/编辑用弹窗（fixed 遮罩 + blur、maxWidth 520、ESC 关闭、body overflow hidden），与登录弹窗同风格。

## 五、部署与验证流程
1. `npm run build > /tmp/b.log 2>&1; echo "EXIT $?"` → 必须 0。
2. `git add <files> && git commit -m "..." && git push origin main`。
3. `sleep 75–80`（Vercel 部署约 60–75s）。
4. 验证：
   ```bash
   curl -sS -m 40 https://bookmark-nav-site.vercel.app/ | grep -c '星轨\|bookmark-card'
   curl -sS -I -m 20 https://bookmark-nav-site.vercel.app/admin | grep -i '^location'  # 未登录应 307 → /
   ```
5. 关键样式改动用浏览器实测（登录后量 getBoundingClientRect / computed style），不要只看截图。

## 六、常见坑速查
| 症状 | 根因 | 解法 |
|---|---|---|
| padding/margin 全部 0px，但 flex/gap 正常 | 非 @layer 全局 reset 覆盖 utilities | 删 reset / 移入 @layer；关键值 inline |
| 页面 CSS 与服务器不一致 | CDN 边缘缓存 / 浏览器 immutable 缓存 | 硬刷新、无痕窗口；或 inline style 兜底 |
| Unterminated regexp literal | JSX 残留孤立 `))}` / 重复 `</div>` | 检查文件尾，删残留，验证 div 平衡 |
| 误删文件头 | 截取重组移动 JSX 区块 | 用相邻块整体替换，替换后查 import/div 平衡 |
| build 报 login/page 缺失 | 删页后 .next 类型缓存 | `rm -rf .next` |
| SQL Editor 整批失效 | 一条语句报错全部回滚 | 拆成多条单独执行 |
| 同一 REST 请求重复多次（如 profiles） | getSession + onAuthStateChange(INITIAL_SESSION) 双通道重复 setUser，useEffect([user]) 重跑 | setUser 前按 uid 去重（useRef 记 uid，相同则跳过） |
