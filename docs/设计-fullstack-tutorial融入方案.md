# fullstack-tutorial 融入方案（设计留档）

> 来源仓库：<https://github.com/frank-lam/fullstack-tutorial>（本地 submodule：`tools/fullstack-tutorial/`）
> 状态：**仅设计留档，未开工、未改动网站与小程序**。
> 编写日期：2026-10-22

## 1. 背景与目标

用户希望把该开源全栈笔记仓库的内容融入 bookmark-nav-site。经实测，仓库共 211 篇 Markdown、约 146.8 万字、630 张配图；核心干货集中在少数几篇，其余为课程提纲、空壳与过时面经。

- **目标**：做一个精选「全栈学习手册」，Web 优先，小程序做轻量入口。
- **非目标**：不整本照搬、不搬图片、不新建后端、本期不做小程序内嵌正文。

## 2. 实测体积（不含 .git 历史）

| 内容 | 体积 |
|---|--:|
| 全部 Markdown 正文 | 2.16 MB（211 篇） |
| 图片（630 张） | 82.4 MB |
| `.git` 历史（仅本地，不分发） | 66 MB |

各模块正文（KB）：notes 根散篇 909、JavaArchitecture 495、course 227、Python 220、others 面经 87、Kafka 73、JavaWeb 60、Frontend 40、DSA 38，其余不足 10。

## 3. 内容选型

### 3.1 精选接入
- **Java 体系**（`notes/JavaArchitecture/`）：01 基础、02 集合框架、03 并发编程、05 JVM、06 设计模式。
- **计算机基础**（`notes/` 根散篇）：操作系统、计算机网络、MySQL、数据结构与算法、Docker、Git 工作流。
- **少量补充**：Kafka 入门（73KB）、Python《流畅的 Python》选篇。

### 3.2 丢弃 / 不接
- `course/` 32 门课程视频提纲（多为目录式，价值低）。
- AI / 前端 / 分布式零散空壳（几乎无正文）。
- `others/interview/` 2018 秋招面经（时效性差，不收录）。
- 全部 630 张配图（82MB），不搬运、不打包，需要时外链。

## 4. PC / H5（Web）方案

- **形态**：复用现有 `GuideShell` 通用壳，新增路由 `/learn-fullstack`（独立页面，不与 learn-agents / learn-dev 混）。
- **数据**：精选正文转成与现有一致的 JSON（`meta + tracks/stages/tasks/resources`），放 `packages/shared-data/src/`，Web 本地静态渲染。
- **图片**：不搬文件；正文配图改引 GitHub raw 或对象存储，纯文字要点直接展示。
- **后端**：不需要，保持静态站。
- **接入点**：抽屉菜单 / 首页学习成长区新增入口。

## 5. 小程序方案（关键：全量装不下）

硬约束：主包 ≤2MB、单个分包 ≤2MB、全部分包合计 ≤20MB；现状小程序**零网络请求**，全部本地读共享 JSON，`shared-data` 已 2.9MB。

| 路线 | 做法 | 适用 | 成本 |
|---|---|---|---|
| **A（推荐，先做）** | 本地只存目录索引 + 每篇一句话摘要（几十 KB），点击用 `web-view` 打开 Web H5 对应页，正文与图均不内嵌 | 零新依赖、最快落地 | 低 |
| B（备选） | 仅把最小模块（Kafka 73KB、Frontend 40KB、DSA 38KB）单独打一个分包，大图外链 | 想离线看少量内容 | 中，仍受 2MB 分包限制 |

> 明确：Java 495KB、操作系统/网络等大部头两条路线都不内嵌；2.16MB 全量文本已顶主包红线，82MB 图更不可能。远期若要小程序内直读全文，需新增 `Taro.request` 网络层 + 域名白名单，属新阶段，本期不做。
